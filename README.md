# bds
синий экран

запуск
pip install Pillow

git clone https://github.com/Ex1fa9/bds.git && cd bds && python main.py

после запуска появляется фейковый экран смерти виндоус котоырй не вырубается с alt+F4 и Escape
выключить можно нажав F8 либо alt+tab и закрыть консоль

смените в main.py poshalko на True если хотите чтобы на 1488 была анимация. по умолчанию она выключена и работает до 99
